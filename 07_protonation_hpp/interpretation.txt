# 07_protonation_hpp — H++ protonation-state assignment and acceptance audit

## What this step did
Submitted the protein-only, TER-delimited structure to the H++ server for protonation-state
assignment, then audited the returned structure against the frozen template and classified
all heavy-atom drift before accepting.

## Key numbers
- Input: 1010 atoms per chain, residues 1-127, three chains
- Returned: 381 residues, 3153 hydrogens added, 3030 template heavy atoms preserved, 0 added
- Histidines: 9 total, assigned HIE:3, HIP:6
- Drift, backbone: 1527 atoms, max 0.000 A, rms 0.000, >1.0 A count 0
- Drift, all heavy: 3030 atoms, max 2.2452 A, rms 0.1695, >1.0 A count 22
- Peptide links checked 378; missing C-N 0; abnormal C-N 0; disulfides 0
- Non-ff14SB resnames: none

## Acceptance threshold and verdict
Gates: backbone drift <= 0.05 A (measured 0.000), non-flippable side-chain drift <= 0.2 A
(measured 0.000), active-site backbone drift <= 0.05 A (measured 0.000), no active-site
heavy atom moved > 1.0 A. PASS on all four. The 22 atoms above 1.0 A are confined to
flippable ASN/GLN/HIS side chains outside the contact set - the expected signature of
terminal-amide and imidazole flips.

## Literature comparison
None. Protonation assignment has no counterpart in the Claeyssens papers, which do not
document their protonation protocol in comparable detail.

## Caveats and known issues
- OPEN: the H++ run parameters beyond pH 7.0 are recorded ONLY in script comments, and the
  two committed copies CONTRADICT each other. The archived copy states internal dielectric
  80 / external 10; the code-repo step07a and step07b both state internal 10 / external 80.
  hpp_output_from_server.pdb carries no parameter record, only a URL remark. Two records
  against one, and internal 10 / external 80 is the physically conventional assignment for
  a solute in water, but this is NOT established by any committed output. Do not state the
  dielectrics in the write-up until confirmed.
- No DOI is held for the H++ method paper. Needed for the citation.
- H++'s own topology and coordinates are discarded; only its protonation and orientation
  decisions are applied to the frozen template. State this - it is a meaningful protocol
  choice, not a detail.
- step07b_audit_repair_hpp.sh is NOT archived alongside its siblings, unlike steps 01-07a.
